# 要望一覧とコンセプト

## ユーザーの要望原文

> テプラ SR 5900 からラベルを出力するAndroid アプリを作ってください  
> 部屋を整理する時にこのラベルが欲しいな と思って いちいちパソコンに戻ったり スマホで文字入力したりするのめんどくさいので音声入力で入力内容確認して OK を押せばラベルの幅に合わせて簡単に印刷してくれる 何部 印刷するかも指定できるけど デフォルトは1  
> そんなやつ APK で出してください

※ 製品の正式な型番は **SR5900P**。実装もSR5900Pを対象にしています。

## 解決したいこと

部屋を整理している最中に、ラベルが必要になるたびPCへ戻ったり、スマートフォンで長い文字を入力したりする手間をなくすこと。片手でスマートフォンを持ち、話して、確認して、すぐ印刷できる道具を目指します。

## 中心となる操作

1. 大きなマイクボタンを押す。
2. ラベルにしたい内容を日本語で話す。
3. 認識された文字を画面で確認し、必要なら修正する。
4. 必要なら印刷枚数を変更する。初期値は1枚。
5. 「この内容で印刷」を押す。
6. プリンターの装着テープ幅に合わせたラベルが印刷される。

## 必須要件

| 項目 | 要件 |
|---|---|
| 対象端末 | Androidスマートフォン |
| 対象プリンター | KING JIM「テプラ」PRO SR5900P |
| 入力 | 日本語の音声入力を主操作にする |
| 確認 | 認識結果を大きく表示し、印刷前に確認・手修正できる |
| 印刷実行 | 確認後に明確なOK操作で印刷する |
| レイアウト | 装着中のテープ幅に合わせて自動調整する |
| 部数 | 指定可能。デフォルト1枚 |
| 提供形式 | 端末へ直接インストールできるAPK |
| 操作感 | 整理作業を止めず、できるだけ少ない手順で使える |

## 採用したUX方針

- 画面中央に大きなマイクボタンを置く。
- 認識内容は大きな編集欄に表示する。
- 印刷ボタンは「この内容で印刷」とし、押す意味を明確にする。
- 印刷枚数は1〜99枚、起動時は1枚とする。
- プリンター状態、テープ幅、進行状況、エラーは日本語で表示する。
- 最近印刷した8件を端末内に保存し、音声入力し直さず再利用できるようにする。
- 接続設定は普段の印刷フローから分離し、一度選んだSR5900Pを記憶する。

## 自動レイアウトの考え方

- SR5900Pから装着テープ幅を取得する。
- 対応幅は4 / 6 / 9 / 12 / 18 / 24 / 36mm。
- テープ幅と文字量を見て、フォントサイズ、1行または2行、ラベル長を調整する。
- ラベル長は28〜120mmの範囲に収める。
- 読みやすさを優先し、太字のサンセリフ体で描画する。

## 受け入れ条件

- Android 11以上の端末で起動・権限許可・音声認識ができる。
- 同じWi-Fi上のSR5900Pを検索・選択・記憶できる。
- 音声認識結果を確認・編集できる。
- 空欄のまま印刷できない。
- 1〜99枚を指定でき、初期値が1枚である。
- 実機のテープ幅を取得し、その幅に合ったラベルを生成できる。
- 印刷成功・失敗を日本語で理解できる。
- 同じ署名鍵で更新APKを作成できる。

## 対象外・混同防止

- SR-R2500P / SR-R5600P向けの別アプリや別ソースは、この案件の対象外です。
- クラウド同期、アカウント、共有ラベル帳、PC連携はv1.0.0の要件ではありません。
- 音声認識自体は端末に設定されたAndroid音声認識サービスを利用します。
