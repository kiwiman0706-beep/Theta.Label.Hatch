## 既知の制約

### 音声認識サービスへの依存

音声認識はAndroid端末に設定されている認識サービスを使います。端末や設定によって、インターネット接続の必要性、精度、候補数、データ取り扱いが異なります。

### Wi-Fi・機器検索

- スマートフォンとSR5900Pは同じWi-Fiネットワークへ接続する必要があります。
- ゲストWi-Fi、端末間通信を遮断するアクセスポイント、VPN、マルチキャスト遮断環境ではプリンターが見つからない可能性があります。
- 検索タイムアウトは約14秒です。見つからない場合は権限、同一SSID、プリンターのネットワーク状態を確認して再検索します。

### Android権限

- Android 12以前ではWi-Fi機器検索のため位置情報権限が必要になる場合があります。
- Android 13以降では近隣Wi-Fi機器の権限を使用します。
- 権限を拒否した場合、プリンター検索が機能しません。

### 公式SDKの再取得

再ビルド時はKING JIM公式サイトで使用許諾に同意し、TEPRA-Print SDK for Android v1.4.0を取得する必要があります。SDKのJAR/SOは展開ソースには含まれていません。配置先は `IMPLEMENTATION_STATUS.md` と `source-expanded/README.md` を参照してください。

### 署名鍵の管理

この引き継ぎZIPには秘密署名鍵が含まれます。公開共有しないでください。更新APKを作る場合は同じ鍵を必ず使用し、鍵ファイルとパスワードを安全な場所にもバックアップしてください。

### SDK表記と利用範囲

SDKの使用許諾条件に従い、アプリ内および通知文書に次の表記を維持してください。

```text
Powerted by KING JIM TEPRA-Print SDK
```

この綴りは既存の指定表記として、そのまま維持しています。利用は日本国内を前提としています。

## 推奨する次の順序

1. 元APKをAndroid端末へインストールする。
2. 実機テストチェックリストを一巡する。
3. 発見した不具合を再現条件付きで記録する。
4. 必要な場合のみソースを修正し、versionCode / versionNameを更新する。
5. 同梱の既存キーストアで署名する。
6. 旧版をアンインストールせず上書き更新できることを確認する。
7. 修正版でも実機テストを再実施する。
