# 開発履歴

## 2026-09-27 — 要望整理

- SR5900Pからラベルを出力するAndroidアプリという依頼を受領。
- 部屋の整理中にPCへ戻る手間と、スマートフォンで文字入力する手間を減らすことを中心課題とした。
- 「音声入力 → 内容確認・必要なら修正 → OKで印刷」を主要フローとした。
- 装着テープ幅への自動フィット、印刷枚数指定、デフォルト1枚、APK納品を必須要件とした。

## 調査・設計

- 対象機種の正式名称をKING JIM「テプラ」PRO SR5900Pとして実装範囲を固定。
- 非公開プロトコルを推測せず、KING JIM公式 TEPRA-Print SDK for Android v1.4.0を使用する方針を採用。
- 同一Wi-Fi内でプリンターを検索・選択し、以後の選択を端末へ記憶する構成とした。
- 整理作業中の片手操作を想定し、大きなマイク、確認しやすい文字欄、明確な印刷ボタンを採用。
- 再入力の負担を減らすため、最近印刷した8件の履歴を追加。

## 実装

- Javaによる2画面構成を実装。
- Android標準の音声認識Intentを利用した日本語音声入力を実装。
- SR5900Pの検索、選択、状態取得、テープ幅取得、印刷を公式SDK経由で実装。
- 文字量とテープ幅に基づく1行/2行、文字サイズ、ラベル長の自動調整を実装。
- 1〜99枚の部数指定、日本語の進捗・エラー表示、端末内履歴を実装。
- Android 11以上、targetSdk 35のAPKとして構成。

## ビルド・成果物

- v1.0.0 APKを専用キーストアで署名。
- 4 ABI（arm64-v8a / armeabi-v7a / x86 / x86_64）をAPKへ収録。
- APK、更新用ソースZIP、SHA-256一覧を作成。
- 公式SDKバイナリは再配布条件を考慮し、更新用ソースZIPから除外。再ビルド手順と配置先をREADMEへ記載。
- 今後の上書き更新用に署名鍵と署名情報を更新用キットへ収録。
