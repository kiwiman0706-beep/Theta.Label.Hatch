# SR5900P 実機テストチェックリスト

## 事前準備

- [ ] Android 11以上のテスト端末を用意する。
- [ ] SR5900Pへテープカートリッジを装着する。
- [ ] スマートフォンとSR5900Pを同じ通常Wi-Fiへ接続する。
- [ ] VPN、ゲストWi-Fi、APアイソレーションを一時的に無効化する。
- [ ] SR5900Pの型番とファームウェアバージョンを記録する。
- [ ] APKのSHA-256が `2497668a10dee6d630c678b277d77d8b2cd5b7e4ebf56a9bc9dd3d8f3b2b368e` と一致する。

## インストール・初回起動

- [ ] `original-deliverables/koe-de-tepra-1.0.0.apk` をインストールできる。
- [ ] アプリ名「声でテプラ」とアイコンが表示される。
- [ ] 初回起動でクラッシュしない。
- [ ] 必要なWi-Fi検索権限を許可できる。
- [ ] マイクを押した際、音声入力に必要な案内または音声認識画面が正しく出る。

## プリンター検索・記憶

- [ ] 右上の「設定する」から検索画面を開ける。
- [ ] 14秒以内を目安にSR5900Pが一覧へ表示される。
- [ ] 別機種や無関係なサービスをSR5900Pとして表示しない。
- [ ] SR5900Pを選択してメイン画面へ戻れる。
- [ ] アプリを終了・再起動しても選択済みプリンターが保持される。

## 基本印刷

- [ ] マイクを押し、日本語を話すと認識文字が編集欄へ入る。
- [ ] 認識内容を手で修正できる。
- [ ] 印刷枚数の初期値が1である。
- [ ] 「この内容で印刷」で1枚だけ印刷される。
- [ ] 印刷中・完了が日本語で分かる。
- [ ] 印字が欠けず、上下左右の余白が不自然でない。
- [ ] 印刷後に正しくカットされる。
- [ ] 履歴へ追加され、履歴から同じ内容を再利用できる。

## 複数枚

- [ ] 2枚指定で同じラベルが2枚出る。
- [ ] 5枚指定で5枚出る。
- [ ] 各ラベルが意図どおりカットされる。
- [ ] 0や100など範囲外を指定できない、または1〜99へ補正される。

## 異常系

- [ ] 未設定状態で印刷しようとした際、設定を促す。
- [ ] 空文字で印刷しようとした際、印刷せず案内する。
- [ ] SR5900Pの電源を切った状態で接続失敗を日本語表示する。
- [ ] テープなしを日本語表示する。
- [ ] カバーを開けた状態を日本語表示する。
- [ ] テープ切れ、使用中、過熱など、可能な範囲で表示を確認する。
- [ ] 権限拒否時にクラッシュせず、再設定方法が分かる。
- [ ] Wi-Fi切断中にクラッシュしない。

## 更新テスト

ソース修正後にのみ実施します。

- [ ] versionCodeを10000より大きくする。
- [ ] `release-signing.jks` の既存鍵で署名する。
- [ ] v1.0.0をアンインストールせず更新APKをインストールできる。
- [ ] 保存済みプリンターと履歴が維持される。
- [ ] 更新後も基本印刷テストが通る。
