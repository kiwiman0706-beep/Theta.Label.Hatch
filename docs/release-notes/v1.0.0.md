## 声でテプラ 1.0.0（versionCode 10000）

KING JIM「テプラ」PRO **SR5900P** へ、Androidスマートフォンから音声でラベルを印刷するアプリです。
このリリースは、前開発スレッドで作成した署名済みAPKを**そのままのバイト列で**公開したものです（再ビルドなし）。

### できること
- 大きなマイクボタン → 日本語で話す → 認識結果を確認・修正 → 「この内容で印刷」
- 装着テープ幅（4/6/9/12/18/24/36mm）を自動取得し、文字サイズ・1行/2行・ラベル長（28〜120mm）を自動調整
- 印刷枚数 1〜99枚（初期値1枚）、ラベルごとのカット（対応時はハーフカット）
- 最近印刷した8件を端末内に保存して再利用
- 同じWi-Fi上のSR5900Pを検索・選択・記憶

### インストール
- Android 11以降。`koe-de-tepra-1.0.0.apk` をダウンロードし、「提供元不明のアプリ」を許可してインストールします。
- スマートフォンとSR5900Pを同じWi-Fi（ゲストWi-Fi・APアイソレーション不可）へ接続し、右上「設定する」からプリンターを選びます。
- 署名証明書 SHA-256: `61256bf31586fd7c266a11c0de663c515fbbdb0667970ad833e62c14f8ce2c79`（リリースCIで `apksigner` 検証）
